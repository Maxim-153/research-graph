# Семантический поиск научных публикаций с визуализацией связей

Веб-сервис для первичного обзора научной литературы. По текстовому запросу он
получает публикации из открытых библиографических источников, группирует их по
смыслу, строит интерактивный граф связей и формирует оформленный список
литературы. Сервис разворачивается локально и работает целиком на открытых
данных (OpenAlex, Crossref), без платных или закрытых компонентов.

## Возможности

- поиск публикаций по теме и диапазону лет через OpenAlex;
- восстановление неполных библиографических метаданных каскадным запросом к Crossref;
- семантическая группировка результатов: эмбеддинги Sentence-BERT, кластеризация
  методом k-средних с автоматическим подбором числа групп по коэффициенту силуэта;
- автоматическое именование тематических групп по мере TF-IDF;
- ранжирование выдачи по смысловой близости к запросу;
- интерактивный граф публикаций с тремя типами связей — прямое цитирование,
  библиографическое сопряжение и семантическая близость — и фильтром по типам;
- интегральная оценка влиятельности публикаций;
- выявление слабо связанных тематических групп (исследовательские разрывы);
- граф соавторства, фильтр по годам, догрузка цитирующих работ;
- отбор публикаций в список и его экспорт по ГОСТ Р 7.0.5—2008 и
  ГОСТ Р 7.0.100—2018, а также в форматах BibTeX, Markdown и JSON;
- файловый кэш ответов внешних источников.

## Технологии

- Серверная часть: Python, FastAPI; Sentence-Transformers (all-MiniLM-L6-v2),
  scikit-learn (k-средних, TF-IDF), NumPy.
- Клиентская часть: React, Vite, React Flow, Dagre.

## Запуск

### Серверная часть

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn main:app --reload
```

Параметры в `backend/.env` — контактная почта для OpenAlex и разрешённые
источники CORS:

```env
OPENALEX_MAILTO=your_email@example.com
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

### Клиентская часть

```bash
cd frontend
npm install
copy .env.example .env
npm run dev
```

Адрес сервера задаётся в `frontend/.env` (по умолчанию `http://127.0.0.1:8000`):

```env
VITE_API_URL=http://127.0.0.1:8000
```

## Структура

- `backend/main.py` — REST-интерфейс: поиск и догрузка связанных работ.
- `backend/semantic_api.py` — адаптер к OpenAlex и Crossref, файловый кэш.
- `backend/ml_processor.py` — векторизация, кластеризация, именование групп, ре-ранжирование.
- `backend/graph_edges.py` — построение трёх типов рёбер графа и метрики связности.
- `backend/eval_metrics.py` — измерительный скрипт на фиксированном наборе запросов.
- `frontend/src/App.jsx` — основной экран и состояние приложения.
- `frontend/src/graphUtils.js` — аналитика графа: влиятельность, разрывы, типы связей, граф авторов.
- `frontend/src/layoutUtils.js` — раскладка графа (Dagre).
- `frontend/src/exportUtils.js` — формирование списка литературы.

## Измерения

Скрипт `backend/eval_metrics.py` считает воспроизводимые метрики на фиксированном
наборе запросов: длительность запроса и эффект кэширования, полноту метаданных до
и после обогащения, коэффициент силуэта и связность графа в трёх конфигурациях.
Результаты сохраняются в `backend/eval_results.json`.
